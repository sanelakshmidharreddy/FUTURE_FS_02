# 🚀 Nexus CRM

Nexus CRM is a modern AI-powered Customer Relationship Management platform built to simplify customer handling, workflow management, and business productivity through intelligent automation and real-time tracking.

---

## 🌟 Project Overview

In today’s digital business environment, managing customer relationships efficiently is extremely important. Traditional spreadsheets and manual systems often reduce productivity and create workflow challenges.

Nexus CRM was developed to provide a smarter and scalable solution for businesses, startups, and teams by combining:

- AI-powered assistance
- Customer management
- Real-time workflow tracking
- Secure authentication
- Modern UI/UX
- Cloud deployment

This project represents a complete full-stack application integrating frontend, backend, database management, authentication systems, and AI services.

⚙️ Workflow
Step 1 — User Authentication
Users can securely register and log in using JWT authentication.
Step 2 — Dashboard Access
After successful login, users access the CRM dashboard.
Step 3 — CRM Management
Users can:
Manage leads
Track activities
Monitor workflows
Receive notifications
Step 4 — AI Assistance
Gemini AI enhances productivity through intelligent support and automation features.
Step 5 — Database Storage
All customer and workflow data is securely stored in MongoDB Atlas.


🌐 Deployment Workflow
Vercel
Used for frontend deployment and fast hosting.
Render
Used for backend deployment and server hosting.
MongoDB Atlas
Used as cloud database storage.


🔑 Environment Variables
Create a .env file and add:
Environment
GEMINI_API_KEY=your_api_key
APP_URL=your_deployed_url
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
